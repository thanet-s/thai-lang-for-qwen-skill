# Thai Lang Guard (for Qwen)

modelตระกูล Qwen trainมากับข้อมูลภาษาจีนปริมาณมาก เวลา generate คำสั้นๆ หรือ
เครื่องหมายวรรคตอนที่บริบทรายรอบอ่อน ความน่าจะเป็นของ token ฝั่งจีน/เอเชียตะวันออก
ชนะได้ เช่น 或 หลุดมาแทน หรือ หรือพิมพ์ ，：（）แบบ full-width อาการนี้เป็น artifact
ของmodel ไม่ใช่ตั้งใจ — ตรวจก่อนส่งเสมอ

## สไตล์การเขียนภาษาไทย (ใช้ควบคู่กับการตรวจ bleed)

คำทับศัพท์ ศัพท์เทคนิค หรือศัพท์เฉพาะ ให้เขียนเป็นภาษาอังกฤษตรงๆ
ไม่ต้องทับศัพท์เป็นไทย เช่น:

- ใช้ linter, script, file, font, deliverable, template, deploy, review, bug
  ไม่ใช่ ลินเทอร์, สคริปต์, ไฟล์, ฟอนต์, เดลิเวอเรเบิล, เทมเพลต
- ชื่อตัวเขียน/มาตรฐาน: Unicode, codepoint, emoji, token, model, prompt
- คำไทยแท้ที่ใช้กันอยู่แล้ว (ตรวจ, บริบท, เครื่องหมายวรรคตอน, คำเชื่อม) คงเป็นไทยได้ตามธรรมชาติ

เหตุผล: คำทับศัพท์สะกดได้หลายแบบ (ลินเทอร์/ลิ้นเทอร์/ลินเต้อร์) อ่านยากและไม่ search เจอ
ส่วนศัพท์อังกฤษในข้อความไทยเป็นเรื่องปกติของคนอ่านเทคนิคอยู่แล้ว

## ใช้เมื่อไหร่

- **ทุกครั้งที่ต้องเขียนคำตอบเป็นภาษาไทย** ไม่ว่าจะสั้นหรือยาว (ตอบสั้นๆ ก็ self-check ก่อนส่ง)
- สร้าง deliverable ที่เป็น file ภาษาไทย → รัน script ประกอบ
- ผู้ใช้รายงานว่ามีจีนปน (ไทยปนจีน, 或โผล่, font จีนเด้ง) หรือขอตรวจข้อความ

## ข้อความสั้น: self-check ในหัวก่อนส่ง

Scan ข้อความสุดท้าย มองหาอักขระกลุ่มต้องสงสัย:

- Han characters (CJK ideographs): U+4E00–U+9FFF (รวม U+3400–U+4DBF, U+F900–U+FAFF)
- Japanese kana: U+3040–U+30FF · Korean Hangul: U+AC00–U+D7AF
- เครื่องหมายจีน/full-width: U+3000–U+303F, U+FF00–U+FFEF

คู่หลุดบ่อย — พบข้างซ้าย ให้แก้เป็นข้างขวา:

| พบ | ควรเป็น |
|---|---|
| 或 | หรือ |
| 的 | ของ / ที่ |
| 是 | คือ |
| 有 | มี |
| 在 | ใน |
| 了 | แล้ว |
| 和 | และ |
| 不 | ไม่ |
| 很 | มาก |
| ， | , |
| 。 | . |
| 、 | , |
| ： | : |
| ； | ; |
| ？ | ? |
| ！ | ! |
| （ ） | ( ) |
| ＂ ＇ | " ' |

## ข้อความยาว / file deliverable: รัน script

script อยู่ใต้โฟลเดอร์ของ skill นี้ (`scripts/check_bleed.py`) รันด้วย:

```bash
python3 -I <skill-dir>/scripts/check_bleed.py <file> [<file> ...]
python3 -I <skill-dir>/scripts/check_bleed.py --text "ข้อความไทยที่ต้องตรวจ"
echo "..." | python3 -I <skill-dir>/scripts/check_bleed.py
```

รายงาน file:line:col พร้อม codepoint บริบท และคำแนะนำแก้ (exit 1 เมื่อพบ)
แล้วแก้เองตามรายงาน — script รายงานอย่างเดียวไม่ edit เพราะบางจุดมีจีนโดยเจตนา (ดูล่าง)

## ข้อควรระวัง (อย่าลบมั่ว)

- ถ้าเรื่องที่กำลังเขียน**เกี่ยวกับภาษา/จีนโดยตรง** (คำแปล, ชื่อเฉพาะจีน, อ้างอิง source จีน)
  ให้อดใจไว้หรือส่ง `--allow` เพิ่มตัวที่จงใจใช้ — อย่า "แก้" สิ่งที่เป็นเนื้อหา
- การสาธิตอาการ bleed เอง (เช่น shows 或 vs หรือ) เก็บตัวจีนไว้ใน quoted/code spans เท่านั้น
- emoji และเครื่องหมายไทย (ๆ, ฯ) ไม่ถือเป็น bleed — script ไม่ flag กลุ่มเหล่านั้นอยู่แล้ว
